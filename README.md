# YL-TextLab

YL-TextLab 是一个完全运行在浏览器中的本机文件处理工具箱，现已提供关键词替换、Notion 文本切分、PDF 查看、图片格式转换与压缩、音频转换、音视频分割、音频相减、频谱画 MIDI 及主唱净化，并支持深浅主题、帮助文档和更新日志。

主唱净化位于 `/audio-vocal`，用于已经分离出的人声音轨。默认“自然保留”：35% 抑制强度、原声道、保护齿音和气声；提供三档预设、弱声门限、音域范围和原 / 居中 / 左 / 右声道选择。可从指定秒数生成 20 秒试听，再处理整段；提供原声、净化人声和被削弱声音的对照试听及独立 WAV 下载。音频先通过本机 FFmpeg 按原采样率解码，释放解码引擎后交给 Worker 执行音高跟随、柔和谐波掩码和弱声抑制，保持原声道模式的立体声相位；0% 旁路净化，声道选择仍生效。支持取消、重试和结果失效后的重新处理，不覆盖源文件。

主唱净化预计算谐波插值、连续音高邻域与重叠相加系数，相同音高复用掩码；静音文件跳过 FFT。对齐的解码 PCM 直接移交 Worker，处理结果直接写入两份 WAV 的数据区，避免解码后的整段复制和两次完整 WAV 编码复制。重复选择当前预设保留有效结果，改变试听起点会清除旧片段；比较位置超出片段时从片段起点开始，快速切换引起的播放中断不再误报格式错误。0% 明确标为原声对照，不显示虚假的旋律跟随覆盖率。

此方法突出较强、连续的旋律，不识别歌手身份；同音高重叠的和声、混响及强干扰可能保留。高强度可能损伤音色、尾音和咬字，覆盖率仅表示活动片段的稳定音高检测比例。思路参考[音高估计与人声分离的结合](https://arxiv.org/abs/1604.00192)，本实现不包含论文中的 RPCA 或训练模型。输入最多 500 MB、8–192 kHz、单 / 双声道；整段最长 10 分钟，解码后最多 128 MB，超限可先试听短片段。输出为原采样率 32 位浮点 WAV，不保留标签与封面。处理改变采样，属于声音编辑；居中合并会抵消左右反相内容。所有音频留在本机，不持久保存。

音频相减现提供“严格 A−B”和“仅消减可靠匹配片段”两种模式。严格模式在 A 静音、B 有声时会留下反相 B；保护模式仅消减局部高相关、能量下降且不新增过载的窗口，其余位置保留 A，边界在匹配区域内部淡化，不做整段防削波衰减。保护模式可配合自动对齐，不进行语义声源识别，分析失败不退回严格相减。结果新增全段 A/B/C RMS 与峰值图、统一 dBFS 刻度、防削波前后对比及同步定位试听。统计覆盖全部解码采样、图表最多 800 窗口；保护分析最多 16,000 窗口，控制轨复用不可变 Blob，避免额外分配完整 A/B PCM。

添加 A/B 后会按 1 MB 分块比较文件完整字节，相同内容显示“同文件提示”，支持改名副本；同名同大小但内容不同不会误判。比较可随替换、清空取消，不读取整份文件到内存、不上传、不持久保存；不同编码或标签但听感相同的音频不在此字节级判定范围内。

频谱画 MIDI 位于 `/audio-midi`：导入音频后在本机 Worker 中计算短时傅里叶频谱，纵轴按 A0–C8 对数音高排列。支持画音符、移动、拉伸、力度与时间数值编辑、节拍吸附、时间缩放、60 步撤销重做，以及原音频/MIDI 同步试听。导出单轨标准 `.mid`（960 PPQ，速度与力度保留），同音高重叠音符合并。音符采用实际秒数保存，修改 BPM 不移动音符。可保存和载入 `.yl-midi.json` 工程（不含音频），不自动保存、不上传。音频最多 100 MB / 10 分钟、单/双声道、2,000 音符；以 22.05 kHz 分析，FFT 2048/4096/8192 可选，频谱最多 6,000 帧。频谱用于人工判断，不做自动音符识别；泛音、低频分辨率和混音可能干扰判断。

同页新增“去除频谱”：拖动框选时间与频率，或输入秒数 / Hz 精确调整，最多 50 个区域；支持独立撤销重做、停止重试和原音频 / 处理结果对照。真正去除音频中的选定频段，始终从原文件重新计算，未选时间保留原解码采样。导出按原采样率及单/双声道生成 32 位浮点 WAV，不经过预览降采样，不保留标签 / 封面。解码使用按需加载的本机 FFmpeg，频谱消减在 Worker 中以 Hann 窗重叠相加执行，时间与频率边缘平滑过渡。处理限制为原文件 100 MB / 10 分钟、至少 8 kHz、解码后 128 MB。画布显示约 27–4307 Hz，其他频段可数值指定至原采样率的一半。区域内所有重叠声音都会受影响，窄小选区可能残留，不是按声源分离。去除区域与音频不写入 MIDI 工程、不自动保存；离开前请下载 WAV。

音频相减工具位于 `/audio-subtract`，计算 `C = A − B × 音量比例`。可选择、拖入、试听、交换两段音频，调整 B 的音量比例（0–200%）及时间偏移（±60 秒，按 A 的采样率取最近采样点）。输出以 A 的时长和采样率为准，自动重采样 B；单/双声道均支持，但两份文件声道数必须相同。B 未覆盖到的位置保留 A。输出为 32 位浮点 WAV，默认只在幅度溢出时整体衰减防削波，并显示真实调整量。每个输入 500 MB，结果上限 256 MB；可取消和重试，不上传、不持久保存音频。此功能是波形相减，同源内容需要时间、音量和波形一致才能抵消，不同录音或混音不能保证消除。

可选“自动匹配相似波形”：对多个位置的短片段做归一化互相关，先粗定位，再按原始采样率精细对齐，估计音量和极性。默认以 0 ms 为中心搜索 ±3 秒，支持 ±250 ms / 1 / 3 / 10 秒，中心可调至 ±60 秒；整个搜索范围限制在 ±60 秒。消减强度为 10–100%，可查看采样偏移、估计和应用音量、极性、取样相关系数，并带入手动模式继续微调。需时长可读且至少 0.5 秒；静音、低相关、周期性歧义或取样偏移不一致会停止自动消减。仅做整段统一偏移，不拉伸时间、不修复变速/混响，相关系数不是消除成功率。FFT 匹配在按需 Worker 中运行，可取消；临时 PCM 片段和输出在结束时释放。手动模式另支持反转 B 的极性。

图片工具可批量转换格式或压缩 PNG、JPG、WebP。常规压缩默认保留原格式，可设 1–50,000 KB 目标大小并按需自动缩小尺寸；PNG 保留格式时为无损重编码（启用缩小会改变分辨率）。结果未达目标或比原文件更大时会显示实际情况。常规压缩结果默认移除 EXIF 等拍摄元数据；单图直接下载图片，多图可打包 ZIP。

无损压缩模式保留原格式、尺寸、透明度和图像数据，不经过 Canvas 重编码。PNG 在后台 Worker 中重新压缩原始 IDAT 数据；JPG 保留量化表及编码扫描数据，WebP 保留 VP8/VP8L、透明和动画数据，仅清理注释、文本或 XMP 等非显示信息。色彩配置及 EXIF 会保留（可能包含拍摄信息）。无损模式不提供质量、目标大小或缩放设置；不能安全减小时保留原文件内容，输出不会比原文件更大。仅支持 PNG/JPG/WebP，其他格式可切回常规压缩或格式转换。

无损压缩导出保留原文件名和扩展名，不添加 `-compressed` 后缀；ZIP 中同名文件放入编号文件夹以避免覆盖。常规压缩仍使用 `-compressed` 后缀。

“文件夹无损压缩”递归读取 PNG/JPG/WebP，自动启用无损模式，保留原文件名和子目录。文件夹批次最多 500 张、总输入 500 MB（普通文件选择仍为 20 张），单张 50 MB、单边 8192 px；其他文件及空目录不会导出。支持 File System Access API 的浏览器可授权目标目录并直接生成新的“原目录名-lossless”结果文件夹，目录重名时自动编号，绝不覆盖原文件。其他浏览器可下载保留目录结构的 ZIP 再解压。

无损流程只检查文件头和原始压缩数据，不解码完整 Canvas；完整结构检查和优化移入可终止的本机 Worker。PNG 验证 chunk CRC、zlib 校验码和解压大小（128 MB 安全上限），保持图像/色彩/方向信息；ZIP 按文件分块构建以降低批量内存峰值。失败项独立报错，停止保留已完成结果；目录写入逐项进行，失败和取消可重试。

压缩页提供 60% / 80% / 90% 质量预设、原图与结果对比、逐项进度和停止处理。批量图片按顺序读取和处理，停止后已完成结果仍可下载。目标大小是每张图片的上限而非整批总量；即使无法达到上限，也会保留最小的有效结果并明确提示。

音频分割工具提供“左右声道分离”：导入双声道歌曲或视频后，可将完整音轨或选区分别导出为 `_L`、`_R` 单声道文件，并独立试听、下载。默认 WAV（PCM）输出，也支持 MP3 或保持原格式；有损格式会重新编码。每个输出只包含原文件的对应声道，单声道及多于两个声道的输入会明确提示。处理全程在本机完成，支持取消与重试。

音频转换工具新增“无损压缩”：支持 16/24 位整数 PCM WAV、AIFF 和 FLAC，输出 `原文件名-无损.flac`，固定保留原采样率、位深和声道。使用 FLAC 压缩级别 8，并将原音频与结果解码为 32 位整数 PCM，比较完整 SHA-256 校验值及音频参数，校验失败不提供下载。结果展示前后大小、节省比例与校验状态。已有 FLAC 在保留元数据且没有标签或封面编辑时，若重压缩未减小则直接保留原文件内容；其他情况下如实显示体积增加。MP3/AAC 等有损来源、浮点音频和其他位深不进入此模式。无损指音频采样一致，容器和元数据字节可能变化。

可多选音频、拖入文件夹，或点击音频页的“文件夹无损压缩”。文件夹递归读取 WAV/AIFF/FLAC 并自动启用无损模式，其他文件会跳过并统计；ZIP 保留根文件夹和子目录，同名结果自动编号。按顺序处理，显示整批进度和大小汇总；单项失败不影响后续文件，支持仅重试失败项，停止后继续只处理未完成项，已完成结果仍可下载。空目录不导出，拖入目录最多扫描 10,000 项或 64 层。

音频转换、无损压缩、歌曲信息编辑和音视频分割（含左右声道分离）的单文件上限为 **500 MB**。音频转换队列每批最多 **100 个文件、总输入 2 GB**。无损模式按文件块读取参数，通过 WORKERFS 按需读取源文件，编码与源采样哈希共用一次解码，再独立解码输出进行校验，减少完整文件复制和重复解码。大文件实际可处理规模取决于设备可用内存，建议使用电脑浏览器。

## 音频系统优化

- 五个音频页面提供统一导航；转换队列支持文件名/目录搜索和状态筛选，筛选仅影响显示，不改变处理或下载范围。原音频与结果不会同时播放多个文件。
- 转换、分割、相减与频谱去除复用可取消的本机引擎加载逻辑；首次加载超过 90 秒会提示重试，取消后旧任务不会覆盖新结果。清空或离开工具时释放相应引擎、预览和结果。
- 转换和分割使用 WORKERFS 按需读取原文件，WAV 标签使用分块读取，避免先把整个源文件复制进虚拟文件系统。单个转码/分割输出限制为 256 MB；达到上限的结果不提供下载，避免误把截断文件当成完整结果。
- 分割优先读取容器元数据；需要回退时通过 FFprobe 读取时长。波形按 16 kHz 生成并合并所有声道峰值，仅影响显示，不改变原文件试听和导出参数。超过 64 MB、10 分钟或解码预算时跳过完整波形，可继续通过精确时间导出；分析可停止。
- 频谱画 MIDI 提供试听音量、播放跟随和清空音频；播放指针独立于频谱底图，减少整图重绘。频谱试听使用 22.05 kHz 分析音频，不作为音质比较依据；频段去除导出仍从原文件按原采样率计算。
- 自定义码率允许直接清空重输，离开输入框时校验；处理中锁定相关参数。无法确定原始采样率/声道时不猜测 WAV 输出体积。有文件或编辑内容时，刷新/关闭标签页触发浏览器离开提示；工具内跳转不会自动保存内容，请先下载。

## PDF 阅读、内容编辑与提取

`/pdf` 提供本机 PDF 阅读器：目录／缩略图导航、全文文字搜索及高亮、页码与键盘跳转、文字选择、复制本页、全文 TXT 和当前页 PNG 导出、文档信息、适应宽度／整页、25%–300% 手动缩放、旋转及浏览器全屏。保留页面原生旋转；阅读旋转不写入 PDF，下载原文件保持原始字节。PNG 按当前方向以 144 dpi 渲染，超过 800 万像素或 8192 px 单边时降低输出分辨率。系统查看与打印在新标签页打开原文件，由浏览器 PDF 阅读器打印，密码文件可能需再次解锁。

支持输入正确密码打开加密文档，不保存密码；遵循文档复制与打印权限。文件及搜索索引仅存于当前页面，刷新、关闭或离开后不恢复。每次一个文件、最大 100 MB，先验证类型与文件头；损坏或空文件明确报错。搜索／提取只读取现有文字层，不提供 OCR，多栏文字顺序取决于源 PDF。搜索最多 1,000 条匹配，全文提取最多 2,000 万字符，提取失败不下载部分结果。加载、搜索、导出可取消，切换文件与离开时取消旧任务并释放 Worker、Canvas 和 Object URL。

PDF.js 按需加载；`build/pdfAssets.ts` 随构建发布中文 CMap、标准字体、WASM 解码和 ICC 数据，兼容 GitHub Pages 子路径，不使用外部 CDN。缩略图虚拟化，仅渲染可见页面；文字缓存最多 100 页 / 200 万字符，单画布上限 800 万像素。测试包含自制多页中英、密码、权限、扫描件、超大尺寸及 120 页长文档夹具。

“编辑内容”使用独立 Worker 中的 PDFium 真正替换 / 删除独立文字和图片对象，并支持新增单行文字、设置字号 / 颜色、按页面比例定位插入图片、撤销 / 重做和另存为 `原名-edited.pdf`。每次编辑从不可变的原文件重新应用，失败不会污染下次导出；原文件下载始终保持原始字节。修改文字使用自托管 Noto Sans SC 常规字体，不自动重排段落；采用显式 Unicode CID 映射，避免汉字变成外形相同的部首字符。引擎约 4.7 MB、字体约 10.6 MB，均按需从本站加载，不访问外部 CDN。

编辑限制：独立对象、每次最多 50 步，每页最多 5,000 个对象；图片最大 10 MB / 800 万像素，图片与撤销历史的像素数据总计不超过 32 MB。文字编辑会嵌入字库，导出体积可能增大。复杂嵌套、特殊文字渲染对象只显示不编辑；不提供 OCR、表单或批注编辑。加密或含数字签名的 PDF 不进入编辑，避免移除安全设置或破坏签名。删除对象不等于安全脱敏，不保证移除历史、元数据或隐藏副本。编辑不保存草稿，离开前需另存为；退出时终止 Worker 并释放下载 URL。字体来源与 OFL 许可见 `public/pdf-editor/`，PDFium / EmbedPDF 许可随构建发布。

## 分类导航

- 所有入口统一为「文本与文档」（关键词替换、Notion 切分、PDF）、「图片处理」和「音频处理」三类，目录定义集中在 `src/navigation/tools.ts`。
- 桌面页头提供可搜索的分类面板，手机提供分组导航；可按名称、格式或用途搜索，例如「无损」「歌曲信息」「MIDI」。
- 首页支持按分类筛选；功能中心使用同一目录，`/features?tool=audioSubtract` 等地址可恢复选中的功能说明，支持刷新、前进和后退。
- 原工具路由保持不变。计划中功能仍为静态内容，不出现在可用工具导航中；仅浏览目录不会加载图片或音频处理引擎。

## 本地运行

安装 Node.js 20.19+ 或 22.12+ 后，双击 `一键打开网站.cmd`，或执行：

```powershell
npm install
npm run dev
```

## 质量检查

```powershell
npm run lint
npm test
npm run build
npm run test:e2e
```

`npm run check` 可连续执行代码检查、单元测试和生产构建。`npm run test:e2e` 会先重新构建，再启动独立预览服务，覆盖桌面和移动端；本机使用已安装的 Chrome，CI 使用 Playwright Chromium。

## 维护与清理

当前版本为 1.11.0。工具页面按需加载；导航支持键盘与 Escape 关闭，页面加载失败可重试。音频引擎初始化和 PDF 加载可取消；音频批量 ZIP 分块生成并避免重名覆盖，打包期间也可停止。

```powershell
npm run clean -- --dry-run
npm run clean
```

清理仅删除可重建的 `dist`、`test-results`、`playwright-report` 和 `coverage`，不删除源码、依赖、浏览器草稿或 GitHub 推送控制台。清理后可运行 `npm run dev`；使用预览服务前需重新执行 `npm run build`。`tmp` 为本机临时目录，不纳入版本控制。

## GitHub 推送

双击 `GitHub推送控制台\一键打开GitHub推送控制台.cmd`。控制台已连接到本项目根目录，并使用 `origin` 远程仓库进行安全提交和推送。

远程仓库：<https://github.com/YvanLouise/YL-TextLab>

## 自动部署

推送到 `main` 后，GitHub Actions 会自动执行 ESLint、Vitest、桌面与移动端 Playwright 测试和生产构建，并将站点部署到 GitHub Pages：

<https://yvanlouise.github.io/YL-TextLab/>

首次上线前，请在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

所有内容仅在本机浏览器中处理，不上传服务器。关键词替换和 Notion 文本切分会保存本机草稿，可通过清空删除；PDF、图片、音频与视频文件不会持久保存。
